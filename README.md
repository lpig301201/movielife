# 我們如何活著｜V8.2

## 三種找電影的方法
- 🌲 從人生出發：電影森林
- 🌌 從思想出發：思想宇宙
- 🌙 從今晚的自己出發：當下狀態

## V8.2 新增

### 1. 「今晚，我想想什麼？」正式資料化
新增 `mood-data.js`。新增電影時可直接勾選：
- 我有點迷惘
- 我想碰觸記憶
- 我想理解愛
- 我想想自由
- 我想被狠狠哲學一下
- 我只想好好活著
- 我今天想被安慰一下
- 我想和孤獨待一會兒

電影資料使用：
```js
moods: ["memory", "solitude"]
```

因此推薦不再只靠關鍵字猜測。舊電影若尚未設定 moods，V8.2 暫時保留關鍵字 fallback。

### 2. 新增電影表單與 mood 連動
新增電影時直接勾選 mood，下載的新 `movies-data.js` 會保存這些連結。

### 3. 我的年度電影回望
思想足跡新增年度回望：
- 觀看紀錄數
- 不同電影數
- 重看次數
- 最常出現的思想座標
- 每部電影當年的觀看摘要

## 日常維護
- 電影 → `movies-data.js`
- 哲學思想 → `thought-data.js`
- 當下狀態 → `mood-data.js`
- `index.html` 平常不需要修改
