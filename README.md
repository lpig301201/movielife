# 我們如何活著｜V7

V7 同時升級「結構」與「美術」。

## 主要檔案
- `index.html`：網站程式與版面
- `movies-data.js`：電影資料（新增電影主要只改這個）
- `thought-data.js`：思想宇宙的哲學領域與母題
- 其他 `.jpg / .svg`：視覺素材

## V7 思想宇宙
不再依賴固定 13 題，而是：

`哲學領域 → 核心母題 → 電影自己的問題 → 電影`

目前包含 14 個領域：自我與身分、意識與心靈、自由與選擇、真實與認知、時間與記憶、他者與關係、倫理與道德、社會與權力、存在與生命、死亡與有限、愛與親密、藝術與創作、科技與人類、歷史與集體。

## 新增電影
網站裡的 `➕ 新增電影` 可直接產生新版 `movies-data.js`。未來新增電影通常不需要改 `index.html`。
