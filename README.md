# 我們如何活著｜V8 思想足跡版

## V8 主題
**電影 × 問題 × 當時的我**

V7 建立兩張地圖：
- 🌲 電影森林：電影談人生的哪些地方？
- 🌌 思想宇宙：電影把我們帶向哪些哲學問題？

V8 新增第三條軸：
- 🧭 思想足跡：不同時間的我，是怎麼看同一部電影的？

## V8 新功能

### 🧭 思想足跡
每次觀看都可以留下獨立紀錄：
- 電影
- 日期
- 第一次觀看 / 重看
- 當下最強烈的感受
- 當時的觀看
- 當時留下的問題
- 當時的思想座標

同一部電影可以留下很多筆，不會互相覆蓋。

### 🕰️ 我的觀看年輪
所有觀看依時間排列。可只看某一部電影，觀察不同年份的觀看變化。

### 🌙 今晚，我想想什麼？
不是傳統的「猜你喜歡」，而是依你此刻想碰觸的問題推薦現有資料庫裡的電影：
- 我有點迷惘
- 我想碰觸記憶
- 我想理解愛
- 我想想自由
- 我想被狠狠哲學一下
- 我只想好好活著

## 資料儲存
思想足跡目前存在瀏覽器 `localStorage`：
- 不會自動公開
- 不會自動同步到其他裝置
- 可匯出 JSON 備份

## 日常維護
V8 仍維持資料驅動：

- 新增 / 修改電影 → `movies-data.js`
- 新增 / 修改思想領域與母題 → `thought-data.js`
- 一般新增內容不需修改 `index.html`

只有要新增網站功能或大幅改版時才需要動 `index.html`。
